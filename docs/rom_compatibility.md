# Matriz de compatibilidade

Nenhuma variante está identificada nesta versão inicial. Uma linha em `catalog/roms.json` deve conter `id`, `sha256` (hash do arquivo exato), `region`, `revision` e `format`. Documente separadamente se o hash foi calculado sobre imagem z64/n64/v64 original ou bytes normalizados.

Nunca adivinhar hashes ou publicar dumps de ROM. Cada observação indica núcleo, versão do emulador e configurações relevantes.
